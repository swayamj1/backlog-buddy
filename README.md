# BackLog Buddy

An AI agent, built with the AWS Strands Agents SDK, that triages GitHub issues so
maintainers only see the ones that actually need a decision.

## Status

🚧 Under active development for the AWS "Agents for Humans" Hackathon (submission
deadline: Sept 14, 2026).

## What it does

BackLog Buddy ingests GitHub issues from a repository and:
- Clusters near-duplicate reports together
- Estimates severity and priority for each issue
- Escalates only the issues that genuinely need a maintainer's judgment call
